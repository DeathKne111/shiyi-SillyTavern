# 拾遗 · Shiyi

SillyTavern 的长期记忆扩展。把长篇叙事整理成**可追溯的结构化记忆**，让角色记得住，也说得清「这是多久以前的事」。

## 安装

SillyTavern → **扩展（Extensions）→ 安装扩展（Install Extension）**，粘贴：

```
https://github.com/DeathKne111/shiyi-SillyTavern
```

安装后在扩展列表启用「拾遗」，聊天栏会出现入口按钮。

## 更新

`manifest.json` 已设置 `auto_update: true`，酒馆启动时会检查新版本；
也可在 **扩展 → 管理扩展** 手动点更新。

## 能力概览

| 模块 | 作用 |
| --- | --- |
| 人物与实体 | 角色、地点、物品、组织、概念 |
| 场景与篇章 | 场景切分与叙事时间 |
| 经历与事件 | 谁做了什么、发生在哪里 |
| 状态变化 | 状态增量（`state_delta`） |
| 认知与秘密 | 谁知道什么、谁不知道 |
| 因果链 | 事件间因果，区分「先后」与「因果」 |
| 伏笔与长期影响 | 未回收的线索与后续影响 |

- **证据链**：每条记录绑定原文切片（`evidence_id` + `quote_hash`），可回溯
- **时间锚**：场景从原文抄录叙事时间（如「次日清晨」），召回时以 `time_hint` 交给模型，避免把久远事件说成刚刚发生
- **可配置**：每批整理楼层数、保留最近楼层数、重试次数（上限 20）、请求超时

## 隐私

- 记忆保存在**各聊天自己的** `chat_metadata` 中，不跨聊天共享
- 导出诊断数据不含 API Key
